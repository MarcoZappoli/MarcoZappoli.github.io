# marcozappoli.github.io

Personal academic website of Marco Zappoli, built with [Astro](https://astro.build) and deployed to GitHub Pages.

- Develop: `npm ci` then `npm run dev` (Node 24, see `.nvmrc`)
- Check and build: `npm run check && npm run build && npm run links`
- Routine updates (papers, projects, CV): see [UPDATING.md](UPDATING.md)
